# keyPENS

Proyek sederhana berisi halaman web statis untuk latihan HTML, CSS, dan pengelolaan aset.

Fitur:
- Halaman utama: `index.html`
- Styling: `style.css`
- Folder aset: `assets/` (gambar dan file pendukung)

Cara Menjalankan:
1. Buka `index.html` langsung di browser.
2. Atau jalankan server HTTP sederhana dari folder proyek:

```bash
python -m http.server 8000
# lalu buka http://localhost:8000
```

Panduan Pengembangan:
- Edit `index.html` dan `style.css` lalu muat ulang browser.
- Untuk live-reload, gunakan ekstensi Live Server di VS Code.

Struktur Proyek:
- `index.html` — halaman utama
- `style.css` — stylesheet
- `assets/` — gambar dan file lainnya
- `README.md` — dokumentasi ini

**Tentang Situs Ini**

Situs ini adalah proyek latihan yang dibuat untuk mempelajari dan mendemonstrasikan dasar-dasar pengembangan front-end:

- Tujuan: Menyediakan halaman statis sederhana untuk bereksperimen dengan struktur HTML, styling CSS, dan pengelolaan aset (gambar, ikon, dll.).
- Sasaran pengguna: Pemula yang ingin belajar web development atau siapa pun yang ingin melihat contoh implementasi HTML/CSS minimal.
- Fitur yang diperlihatkan: tata letak responsif sederhana, penggunaan file aset di folder `assets/`, dan struktur file yang mudah dikembangkan.
